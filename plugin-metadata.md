# Plugin directory metadata — Vistaleon Card Price Checker

## Name

Vistaleon Card Price Checker

## Description (use verbatim in the directory listing)

How much is my Pokemon card worth? Ask for any Pokemon card by name and get
its current market price, low and high, for every printing. Add the set to
pin down one version, like "Charizard Base Set". Every answer links the card
on Vistaleon so you can buy it.

## What it does

- Current TCGplayer market price for any Pokemon card, in USD
- Low and high prices per finish (holo, reverse holo, 1st edition)
- Prints from every set, newest to oldest, with card images
- Buy link to Vistaleon on every answer

## Example prompts (what people actually type)

- "How much is my Charizard worth?"
- "What is Umbreon ex from Prismatic Evolutions selling for?"
- "Is my Base Set Charizard worth more than $500?"
- "How much is Espeon ex from the 30th Celebration set?"
- "What does a Delta Reign booster box go for?" (singles only in v1 — the
  tool answers cards; sealed product pricing is a planned v2 addition)

## Keywords for discovery

pokemon card price, how much is my pokemon card worth, charizard price,

## Monetization (per the video's play)

Top-of-funnel exposure. The plugin is free; every answer funnels to
Vistaleon, where the card can be bought. No account needed to check a
price; Vistaleon checkout handles the sale.
